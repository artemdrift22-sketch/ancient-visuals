# Ancient Visuals

Клиентский мод визуальной кастомизации для **Minecraft Java 1.21.1 (Fabric)** в стиле Древней Греции / Олимпа: мрамор, лавры, меандры, лазурь, кобальт и золотые акценты.

Мод **только визуальный и только клиентский**. Нет автокликера, аим-ассиста, ESP/wallhack, обходов античита и изменений скорости атаки или дальности. Все данные HUD берутся из реального состояния игры.

## Как получить .jar через GitHub

GitHub в браузере принимает не больше 100 файлов за раз, поэтому проект загружается одним архивом, а сборщик сам его распаковывает.

1. Распакуй `ancient-visuals-upload.zip`. Внутри три вещи: папка `.github`, архив `ancient-visuals-src.zip` и этот `README.md`. Архив `ancient-visuals-src.zip` распаковывать **не нужно**.
2. Открой репозиторий https://github.com/artemdrift22-sketch/ancient-visuals → **Add file → Upload files**.
3. Перетащи в окно все три элемента (папку `.github` целиком) и нажми **Commit changes**.
4. Открой вкладку **Actions**: запуск **Build** начнётся сам и идёт примерно 5–10 минут.
5. Когда он станет зелёным, файл `ancient-visuals-1.0.0.jar` будет:
   - в разделе **Releases** справа на главной странице репозитория (релиз `build-N`);
   - или внутри запуска, внизу в **Artifacts** → `ancient-visuals-jar` (скачается zip, jar внутри).
6. Положи jar в `.minecraft/mods` вместе с **Fabric API** для 1.21.1. Нужен Fabric Loader ≥ 0.16.

Если папка `.github` не загружается (на macOS она скрыта, показать: Cmd+Shift+.): нажми **Add file → Create new file**, в имени файла набери `.github/workflows/build.yml`, вставь туда содержимое файла `build.yml` (открой его Блокнотом) и нажми **Commit changes**.

Чтобы обновить мод, загрузи новый `ancient-visuals-src.zip` поверх старого: сборка запустится заново.

Если сборка красная, открой шаг с красным крестиком (обычно **Build jar**), скопируй текст ошибки и пришли мне: я поправлю код.

## Управление

- **Правый Shift**: главное меню (поиск, категории, избранное, недавние, инструменты).
- **B**: колесо эмоций.
- У каждого модуля можно задать свою клавишу переключения.

## Что внутри

- **Темы**: 18 оболочек и 20 палитр, редактор темы (токены, превью, проверка контраста, импорт и экспорт).
- **HUD**: 43 элемента и редактор HUD (сетка, привязка, направляющие, выравнивание, мультивыбор, группы, undo/redo, раскладки, безопасная зона). Есть 15 скинов HUD.
- **Прицел**: 12 стилей и хитмаркер.
- **Viewmodel и стили взмаха**: стиль взмаха меняет только анимацию, но не скорость атаки.
- **Частицы**: 80 эффектов, Particle Studio (живое превью, редактирование всех параметров, свои эффекты, импорт и экспорт), адаптивное качество и бюджет частиц.
- **Эффекты**: движения, шлейфы, удары, тотем и фоновые эффекты.
- **Компаньоны**: 20 штук, видны только тебе.
- **Пресеты мира**: оттенок и дальность тумана. Это не шейдер.
- **Профили**: 12 пресетов, сравнение, экспорт и импорт, восстановление.
- **Resource Pack Hub**: включение паков, генерация 16 тематических GUI-паков из ванильных текстур, проверка паков и конфликтов.
- **Texture Lab**: карандаш, ластик, заливка, пипетка, линия, прямоугольник, цветовые операции, undo/redo, сохранение в пак.
- **Диагностика и совместимость**: хуки, моды, лог, безопасный режим, отчёт.

Конфиг хранится в `config/ancientvisuals/config.json`. Запись атомарная, плюс 5 резервных копий и миграции.

## Ограничения текущей версии

- Эмоции показывают только локальные частицы и надпись. Анимации модели игрока нет.
- Плащи, физика предметов и обводки пока не реализованы.
- Ванильные полоски здоровья и голода не скрываются: элементы HUD рисуются поверх или рядом.
- Нет шейдерного конвейера: пресеты мира работают только через туман.
- Русская локализация покрывает основной интерфейс. Остальные строки показываются на английском.

## Разработка

- Локальная сборка: `gradle build` (Java 21, Gradle 8.14). Тесты ядра запускаются в `src/test`.
- `src/main/java/dev/ancientvisuals/core` содержит ядро без зависимостей от Minecraft (JSON, настройки, профили, раскладка HUD, частицы, текстуры, темы).
- `client` содержит интеграцию с Minecraft и Fabric, `mixin` содержит минимальные миксины (все с `defaultRequire 0`).
